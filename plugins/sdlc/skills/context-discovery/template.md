# Context Discovery

Structure of `context-discovery.md`. Keep every section. Write `none` if empty. Use short bullets.

```md
# Context Discovery

## Request Summary
- <1-3 bullets: what is requested and why>

## Confirmed Facts
- <fact> [n]

## Constraints / Requirements
- <item> [n]

## Assumptions
- <assumption> (needs confirmation: yes/no)

## Likely Impacted Areas
- <path or area> - <why> (confidence: high/medium/low)

## Relevant Repository Materials
- <path> - <what it is>

## Risks / Uncertainties
- <item>

## Open Questions
- <question>

## Planning Readiness
- Status: Ready for planning | Partially ready | Not ready for planning
- Reason: <one sentence>
- Missing inputs: <list or none>

## References
- [1] <type: ticket | doc | link | file | repository | user answer> - <key, URL, `path:line` or "User, chat"> (mark unreadable ones)
```
