# Auto Run

Structure of `auto-run.md`. Keep every section. Write `none` if empty. One line per item.

```md
# Auto Run: <feature name> (<ticket key if any>)

- Started: <date>
- Stage: discovery | plan | implement | review | submit | finished
- State: running | waiting | blocked | ready
- Review rounds: <n>
- MR/PR: <link or none>

## Decisions
- <stage> - auto: <decision> (<rule>)

## Escalations
- <stage> - <question> - <answer>

## Stops
- <date> - <stage> - <reason>
```
