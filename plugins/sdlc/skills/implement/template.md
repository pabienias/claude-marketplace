# Implementation Summary

Structure of `implementation-summary.md`. Keep every section. Write `none` if empty. Short bullets. No code.

```md
# Implementation Summary: <feature name> (<ticket key if any>)

- Plan: `implementation-plan.md`
- Branch: `<branch>`
- Verification: `<command>`
- Status: in progress | done

## Decisions
- <decision from Q&A or a blocked phase> - <reason>

## Phases
- Phase N: <title> - done `<commit>` | in progress | not started
  - Deviation: <what differs from the plan and why>

## Follow-ups
- <out-of-scope item or unresolved question> - <where or owner>
```
